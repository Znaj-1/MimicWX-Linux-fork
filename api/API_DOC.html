:8899 MimicWX 内置接口 — Rust 主程序，Docker 容器内

认证方式: Authorization: Bearer <token> 或 ?token=<token>

免认证
GET /status 服务状态 免认证

返回服务运行状态、版本、运行时间、监听数、数据库状态、联系人数

Response: 
{ "status": "LoggedIn", "version": "0.1.0", "uptime_secs": 7200, "db_available": true, "listen_count": 3, "contacts": 16 }
联系人 & 会话
GET /contacts 联系人列表 需认证

从数据库读取所有联系人（需要数据库解密成功）

Response: 
{ "contacts": [{ "username": "wxid_xxx", "display_name": "昵称", "remark": "备注", "alias": "微信号" }] }
GET /sessions 会话列表 需认证

优先从数据库读取，失败时 fallback 到 AT-SPI 读取当前窗口会话

消息
GET /messages/new 增量新消息 需认证

从数据库读取增量新消息（每次调用返回上次之后的新消息）

POST /send 发送文本消息 需认证

通过 AT-SPI 模拟操作微信窗口发送消息，DB 可用时自动验证发送结果

Request Body: 
{
  "to": "显示名或备注名",      // 收件人（用 /friends 接口获取的 name）
  "text": "消息内容",         // 消息文本
  "at": ["张三", "李四"]     // 要 @ 的人（可选，群聊用）
}
Response: 
{ "sent": true, "verified": true, "message": "发送成功" }
POST /send_image 发送图片 需认证
Request Body: 
{
  "to": "显示名",
  "file": "base64编码的图片数据",
  "name": "image.png"          // 可选，用于推断 MIME
}
聊天 & 监听
POST /chat 切换聊天窗口 需认证

切换到指定联系人/群的聊天窗口

Request Body: 
{ "who": "显示名" }
Response: 
{ "success": true, "chat_name": "当前聊天名" }
GET /listen 监听列表 需认证

获取当前正在监听的联系人/群列表（独立窗口模式）

POST /listen 添加监听 需认证

为指定联系人/群弹出独立窗口，实时监听消息

Request Body: 
{ "who": "显示名" }
DELETE /listen 移除监听 需认证
Request Body: 
{ "who": "显示名" }
通用命令
POST /command 通用命令执行 需认证

通过一个接口执行多种操作，支持以下命令：

Request Body: 
{ "cmd": "命令字符串" }
支持的命令: 
"status"              # 查看状态
"atmode"              # 切换仅@模式
"reload"              # 重新加载 config.toml
"listen 张三"         # 添加监听
"unlisten 张三"       # 移除监听
"send 张三 你好"      # 发送消息
调试 & WebSocket
GET /debug/tree?depth=5 AT-SPI2 控件树 需认证

dump 微信窗口的 AT-SPI2 控件树，depth 控制深度（默认5，最大15）

GET /debug/sessions 会话容器子树 需认证

只 dump 会话容器的子树（深度4），用于调试会话列表

WS /ws WebSocket 实时推送 需认证

WebSocket 连接，实时推送新消息和自发消息事件。每 30 秒心跳 Ping。

推送消息格式: 
# 收到新消息
{ "type": "received", "from": "发送者", "text": "消息内容" }

# 自己发送的消息
{ "type": "sent", "to": "收件人", "text": "消息内容", "verified": true }
:9000 Friends API — Python 脚本，systemd 管理

免认证 · 代理 MimicWX 的 /contacts + /sessions，过滤后返回可发消息的对象

GET /friends 好友/群聊分类 免认证

合并 /contacts + /sessions，过滤系统账号（weixin、filehelper、gh_* 等），只返回有会话记录的好友 + 全部群聊。 返回的 name 字段可直接用作 /send 接口的 to 参数。

Response: 
{
  "friends": [
    { "name": "老干妈", "username": "wxid_xxx", "remark": "老干妈", "alias": "yeepay_1" }
  ],
  "groups": [
    { "name": "测试群", "username": "52265460221@chatroom" }
  ]
}
快速参考
常用 curl 示例
# 查看服务状态（免认证）
curl http://localhost:8899/status

# 获取好友/群聊分类
curl http://localhost:9000/friends

# 获取联系人列表
curl -H "Authorization: Bearer <token>" http://localhost:8899/contacts

# 获取新消息
curl -H "Authorization: Bearer <token>" http://localhost:8899/messages/new

# 发送消息
curl -X POST http://localhost:8899/send \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"to":"老干妈","text":"你好"}'

# 添加监听
curl -X POST http://localhost:8899/listen \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"who":"老干妈"}'

# WebSocket 连接
wscat -c "ws://localhost:8899/ws?token=<token>"
服务管理
# MimicWX (Docker)
docker ps                              # 查看状态
docker-compose restart                 # 重启
docker logs mimicwx-linux --tail 50    # 查看日志

# Friends API (systemd)
systemctl --user status friends-api    # 查看状态
systemctl --user restart friends-api   # 重启
journalctl --user -u friends-api -f    # 查看日志
